# 💰 Expense Tracker (Java)

A complete **Java-based Expense Tracker Application** built using Core Java concepts.  
This project helps users manage daily expenses, analyze spending patterns, and export reports.

---

# 📌 Problem Statement

Many students struggle to keep track of their daily expenses and lack awareness of their spending habits.  
This often leads to poor financial management and unnecessary spending.

---

# 💡 Solution

To solve this problem, this application provides a simple and efficient way to:

- Record daily expenses  
- Categorize spending (Food, Travel, etc.)  
- Track total expenses  
- Generate reports (category-wise & monthly)  
- Export reports for analysis  

---

# 🚀 Features

- ✅ Add Expense (title, amount, category)
- ✅ Delete Expense
- ✅ View All Expenses
- ✅ Category-wise Report
- ✅ Monthly Report
- ✅ Total Expense Calculation
- ✅ Export to CSV
- ✅ Export Monthly Report (CSV)
- ✅ GUI using Java Swing
- ✅ CLI version available

---

# 🛠️ Tech Stack

- Java (Core Java)
- OOP (Object-Oriented Programming)
- File Handling (BufferedReader, BufferedWriter)
- Java Swing (GUI)

# 🧠 How It Works

1. User adds expense (title, amount, category)  
2. Data is stored in a file (`expenses.txt`)  
3. User can:
 - View expenses  
 - Delete expenses  
 - Generate reports  
4. Reports can be exported as CSV files
